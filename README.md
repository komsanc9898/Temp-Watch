# Temp Watch — ติดตามอุณหภูมิรถขนส่ง (NiM Express | SEAL Cold Chain)

เว็บแจ้งเตือนรถที่อุณหภูมิผิดปกติให้ DC และบันทึกผลการตรวจสอบ

## ขั้นตอนการทำงาน
1. **นำเข้ารายงาน:** ADMIN หรือ BKK นำเข้า "รายงาน Temperature Dashboard" จากระบบ GPS (ไฟล์ .xlsx หรือลิงก์ Google Sheet)
2. **เปิดเคส:** รถที่สถานะ = วิกฤต / แจ้งเตือน จะถูกเปิดเป็นเคสให้ DC ที่รับผิดชอบ
3. **บันทึกผล:** DC และ BKK เข้าระบบด้วย PIN แล้วบันทึกผลการตรวจสอบ
   - ระบุสาเหตุเป็น รถ / คน / ระบบ
   - ปิดเคสเป็น แก้ไขแล้ว / แก้ไขไม่ได้ (พร้อมสาเหตุ)
4. **Dashboard:** สรุปจำนวนเคสรายวัน สาเหตุ และ % การปิดเคส

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `styles.css`, `app.js` | หน้าเว็บ (static) |
| `assets/` | โลโก้ |
| `apps-script/Code.gs` | Backend บน Google Apps Script (Google Sheet เป็นฐานข้อมูล) |
| `GOOGLE-SHEETS-SETUP.md` | วิธีติดตั้ง Apps Script, ทีม/PIN และการนำเข้ารายงาน |

## ความปลอดภัย
- ข้อมูลรถ เคส และ PIN อยู่ใน Google Sheet (ไม่เปิดแชร์) ไม่ได้อยู่ใน repository นี้
- ทุกคำสั่งต้องเข้าสู่ระบบด้วย PIN และระบบตรวจสิทธิ์ที่ฝั่ง Apps Script
